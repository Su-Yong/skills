# help

`create-ui`의 사용법과 명령 범위를 읽기 전용으로 안내한다. 동작의 기준은 [스킬 진입점](../../SKILL.md)이며, 요청받은 주제의 문서만 추가로 확인한다.

## 호출

```text
$create-ui help
$create-ui help style
$create-ui help migrate
$create-ui help 팔레트를 바꾸는 방법을 알려 줘.
```

예시 속 제작·변경 문구는 설명할 내용이다. `help` 요청에 예시가 포함되어 있다는 이유로 해당 작업을 실행하지 않는다. 파일 생성·설치·서버 시작·미리보기 생성·기술 전환을 수행하지 않는다.

## 기본 안내

주제가 없는 `help`에는 다음 네 가지 사용법을 짧게 안내한다. 모든 상세 규칙이나 명령 문서 전체를 한꺼번에 출력하지 않는다.

| 목적 | 호출 예시 | 설명할 핵심 |
| --- | --- | --- |
| 웹사이트 제작 | `$create-ui 도서 목록과 상세 페이지를 만들어 줘.` | 데이터 포맷과 페이지 계층을 먼저 설계하고 UI와 필요한 서버를 구현한다. |
| 기존 사이트 전환 | `$create-ui migrate 기존 서버는 유지해 줘.` | 기능과 데이터 계약을 보존하며 기술·화면을 전환한다. 기존 서버의 유지·교체를 확인한다. |
| 현재 디자인 확인 | `$create-ui style` | 현재 프로젝트에 적용된 설정과 변경 가능한 항목을 조회한다. |
| 스타일·구조 변경 | `$create-ui style 팔레트를 그린으로 바꿔 줘.` | 현재 프로젝트의 시각적 값, 페이지 계층과 탐색 방식을 수정한다. |

기본 원칙은 데이터 종류별 페이지 구성, 적절한 깊이와 계층, 별도 상세 페이지, 필요한 문구만 사용, 실제 shadcn/ui의 기본 디자인과 Lucide 활용으로 요약한다. 이전 커스텀 스타일 수치를 기본값으로 안내하지 않는다. 모든 명령은 현재 프로젝트를 대상으로 한다는 점을 알린다.

## 주제별 안내

- `help migrate`: [migrate](migrate.md)를 읽고 전환 범위, 기존 기능·계약 보존, 서버 유지·교체 선택과 예시를 설명한다. 도움말을 읽는 단계에서 실제 서버 교체 질문을 시작하지 않는다.
- `help style`: [style](style.md)을 읽고 인자 없는 조회와 자연어 변경의 차이를 설명한다. 페이지 계층·메뉴 변경도 가능한 범위에 포함한다.
- 팔레트·글꼴·간격 질문: [스타일 체계](../style-system.md)에서 관련 부분만 확인한다. 기본 팔레트는 중립이며 블루·그린·바이올렛·오렌지를 선택할 수 있고 각 팔레트가 라이트·다크를 제공한다는 식으로 설명한다.
- 페이지·탐색 설계 질문: [레이아웃 기준](../layout.md)에서 관련 부분만 확인한다. 이동을 줄인다는 의미는 페이지 깊이와 계층 설계이며, 상세 옆 패널이 기본이라는 뜻이 아님을 설명한다.
- UI 컨트롤·아이콘 질문: [컴포넌트 기준](../components.md)을 읽고 실제 shadcn/ui 컴포넌트와 Lucide 사용 방식을 설명한다. Select가 필요한 곳에 단순히 네이티브 선택 상자를 꾸미는 방식은 기본 구현으로 안내하지 않는다.
- Block 참고 질문: [Block 기준](../blocks.md)을 읽고 실제 레이아웃 참고, 허용되는 조정, 후보가 없을 때의 기본 컴포넌트 구성 방식을 설명한다.

문서에서 확인하지 못한 기능이나 지원하지 않는 호출을 만들어 설명하지 않는다. 요청한 명령을 찾을 수 없다면 지원하는 호출과 가장 가까운 사용법을 안내한다.

## 프로젝트 상태와 검증에 관한 질문

사용자가 현재 프로젝트에 적용된 값을 물었다면 필요한 파일을 읽어 실제 값을 확인할 수 있다. 프로젝트가 없거나 값을 확인할 수 없으면 그 사실을 밝히고 스킬의 기본값과 구분한다. 단순 사용법 안내를 위해 저장소 전체를 조사하지 않는다.

검증 방식을 물으면 기존 빌드·관련 검사와 실제 앱의 수동 브라우저 확인을 설명한다. 별도 요청 없이 테스트 파일·테스트 모음·검증 스크립트·테스트 앱을 생성하지 않으며, `help` 자체에서는 빌드나 검사를 실행하지 않는다.

## 응답 형태

질문에 대한 설명과 바로 사용할 수 있는 짧은 호출 예시를 제공한다. 기본값과 현재 프로젝트에서 확인한 값을 구분하고, 필요한 경우 해당 상세 문서의 링크를 함께 남긴다. 사용법 안내를 구현 승인이나 전역 설치·배포 요청으로 해석하지 않는다.
