# 16:9 가로 발표 조판

핵심 사실·수치·출처를 유지한 요약과 순서 재구성을 기본으로 허용한다. 한 장의 핵심 메시지 하나와 그 근거를 중심으로 배치한다. 사용자 원문 보존 지시가 있으면 요약하지 않는다. 아래 수치는 A4 치수의 단순 배율이 아닌 발표용 규격이며, 내장 slides 가이드의 일반 스타일보다 사용자가 선택한 이 체계를 우선한다. 원고에 없는 감성적 구호·마케팅 메시지를 추가하지 않는다.

지정 장수에 맞게 근거를 유지한 요약·구성 조정을 먼저 수행한다. ‘약·목표·가급적’은 목표 분량이며 필요한 증가를 명시할 수 있다. ‘정확히·최대·넘지 않게’는 엄격한 제약이며 부록도 총 장수에 포함한다. 필수 사실을 유지하면서 그 한도를 맞출 수 없으면 사용자에게 명시적으로 허용된 보충자료를 쓰거나 충돌을 알린 뒤 해결한다. 장수를 조용히 늘리지 않는다.

## 캔버스와 안전 영역

모든 슬라이드는 **1920×1080 canvas units**, 가로 16:9다. 좌우 안전 여백은 120, 폭은 1680이다. 핵심 내용의 상하 안전 영역은 y=120–960이고 머리말·쪽수 등 보조 메타정보만 바깥 72 여백 영역을 사용할 수 있다. 중요한 본문·수치·차트 라벨을 가장자리에 붙이지 않는다.

| 구성 | 규격 |
| --- | --- |
| 전체 폭 | x=120–1800, 폭 1680 |
| 2열 비교 | 816 + 48 + 816 |
| 3열 비교 | 528 + 48 + 528 + 48 + 528 |
| 본문 내부 간격 | 16–24 시작값 |
| 다른 큰 블록 사이 | 40–56 시작값 |
| 설명·인용·KPI 패딩 | 32 |
| 표 셀 좌우 패딩 | 24 |
| 기본 구분선 / 주요 선 | 2 / 3 |
| 데이터 선·점의 경계 | 3–4, 실제 배경 대비 3:1 이상 |

프레임 크기는 고정하고 내용이 넘치면 위 분량 제약 안에서 슬라이드를 분할한다. 보이는 글자와 divider 사이 여백은 양쪽이 균형 있게 보이도록 조정하고 그룹 내부 간격은 외부보다 좁게 둔다. 단순 확대 때문에 긴 본문·많은 열·큰 표가 슬라이드에 남지 않게 한다.

## Pretendard 위계

아래 크기·행간은 canvas units다. `lineHeight`에는 행간/크기의 비율을 넣는다. docs의 12pt 본문이나 9pt 주석이 발표 프레임에 남아 있으면 수정한다.

| 역할 | 크기 / 행간 | weight |
| --- | --- | --- |
| 표지 제목 | 112 / 124 | 700 |
| 표지 부제 | 36 / 54 | 500 |
| 장 도입 제목 | 96 / 110 | 600 |
| 일반 제목 | 80 / 96 | 600 |
| 소제목 | 48 / 60 | 600 |
| 부제·리드문 | 44 / 58 | 500 |
| 본문 / 강조 | 36 / 50 | 400 / 600 |
| 구조 라벨·표 헤더 | 28 / 40 | 600 |
| 표 값·축·값 라벨 | 30 / 42 | 400 |
| KPI 숫자 | 96 / 106 | 600 |
| KPI 설명 | 28 / 40 | 400 |
| 인용문 | 48 / 64 | 500 |
| 출처·주석 | 24 / 32 | 400 |
| 탐색 메타정보·쪽수 | 22 / 31 | 400 |

일반 제목은 1–2줄을 우선하고 핵심 결론을 표현하되 원고보다 강하게 단정하지 않는다. 한국어·영문·단위·괄호를 의미 단위로 줄바꿈한다. 본문은 36, 주석은 24를 유지하고 분량 때문에 축소하지 않는다. 표지의 긴 제목은 104/116, 96/108 순서로 조정할 수 있으며, 그래도 넘치면 의미를 보존해 부제를 분리한다.

## 조합 예시와 선택 기준

**표지:** 작은 발행자·유형 정보, 왼쪽의 큰 제목, 부제, 넓은 추상 이미지, 날짜·버전으로 계열을 맞춘다. A4 표지의 요소 순서를 유지하되 가로 판형의 여백을 사용한다. 현재 조합 예시는 긴 제목 허용 규격인 96/108·700과 부제 36/54·500, 1680×352 이미지 프레임을 사용한다. ppt의 이미지 프레임은 13:6에 고정하지 않으며 원본 이미지를 비례 확대·크롭해 넓은 띠에 채운다. 가로·세로를 따로 늘리지 않고 제목·로고는 이미지 밖에 둔다. 제공되지 않은 브랜드명·날짜를 채우지 않는다.

**장 도입:** accent-soft 전면 배경에 작은 장 번호, 96 크기 제목, 필요한 경우 짧은 리드문만 둔다. 앞 장의 상세 내용을 반복하지 않는다. 짧은 발표는 장 도입을 생략해도 된다.

**본문:** paper 배경에 80 크기의 제목과 하나의 설명·비교·수치·절차 관계를 둔다. 2열은 비교 대상이나 설명/근거 등 실제 관계가 있을 때 사용한다. 모든 장에 같은 세 칸을 반복하거나 내용과 무관한 아이콘을 넣지 않는다.

| 원고의 역할 | 적합한 조합 |
| --- | --- |
| 핵심 설명 | 제목 + 짧은 본문 + 필요할 때 설명 상자 |
| 실제 핵심 지표 | 제목 + 1개 큰 KPI 또는 연속 tint 면의 2–3개 KPI + 조건·출처 |
| 동일 기준 비교 | 제목 + 2열 비교 또는 읽을 수 있는 표 |
| 시간에 따른 변화 | 제목 + 큰 선 차트 + 제한 조건·출처 |
| 범주별 크기 | 제목 + 가로 막대 + 직접 값 라벨·출처 |
| 순서·실행 | 제목 + 2–3개 단계 또는 세로 행 + 실제 현재 상태 |
| 정확한 실제 발언 | 제목 또는 짧은 맥락 + 인용 + 발언자·출처 |
| 상세 자료 | 식별 가능한 부록 슬라이드, 본문에서 부록 번호로 연결 |

KPI의 단위·기간·분모는 큰 숫자 가까이에 둔다. 중요한 한계가 작은 주석에만 숨어 결론을 바꾸지 않게 한다. 긴 표는 행·열을 나누고 식별 열·헤더를 반복한다. 4개보다 많은 시계열은 같은 축의 여러 차트로 나누는 것을 우선한다. 긴 인용은 요약문으로 명확히 바꾸거나 추가 슬라이드로 이어가며, 생략·의역한 문장을 정확한 직접 인용처럼 표시하지 않는다.

## 발표 검수

슬라이드 축소 보기와 발표 보기에서 제목·본문·수치의 우선순위가 즉시 구분되는지 확인한다. 100%에서는 깨진 글자·잘린 단위·겹친 값 라벨·읽기 어려운 출처를 확인한다. 한 슬라이드에서 두 논점이 경쟁하면 분량 제약 안에서 나누거나 전체 배분을 조정한다. 부록으로 옮긴 근거의 연결이 유효하고 요약한 주장에 필요한 조건이 본문에 남는지 원고와 대조한다.

최종 PDF는 페이지마다 가로 16:9를 유지하고 요청한 슬라이드 순서를 따른다. 기본 출력은 1920×1080pt의 화면용 PDF이며 인쇄 규격은 별도 요청을 따른다. 출력 프레임을 임의 A4나 Letter로 바꾸지 않는다.
