# A4 세로 문서 조판

기본 편집 정책은 **원문의 문구·순서·사실·수치·인용·출처 보존**이다. 명시적인 요약·편집 요청이 있으면 그 조건을 적용한다. 본문을 임의 요약해 큰 글씨와 빈 공간으로 채우지 않는다. 최대 페이지 수를 명시한 요청과 내용 보존이 충돌하면 한도를 넘기기 전에 충돌을 알린다.

## 캔버스와 단위

원점은 페이지 왼쪽 위다. 배치는 mm, 글자 크기·행간·선은 pt로 정의한다. 이 시스템의 docs 캔버스는 **1 unit = 1pt**, `mm × 72 / 25.4`로 변환한다. A4 프레임은 `595.275590551 × 841.88976378`이다. `lineHeight`는 절대 pt가 아닌 비율이므로 본문 12/18pt에는 `fontSize:12`, `lineHeight:1.5`를 사용한다.

| 전체 | 210×297mm |

상자의 모든 폭은 패딩을 포함한 바깥 폭이다. 1열을 기본으로 하고 비교·단계·KPI 등 정보 관계가 있을 때만 열을 나눈다. 색면 내부에서 열을 만들면 먼저 패딩을 빼고 계산한다. PDF의 실제 판형 검수는 [출력 절차](pen-workflow.md)를 따른다.

기본 자간은 0, 왼쪽 정렬이다. 절 번호·절 이름은 머리말, 핵심 주제는 H2로 나눈다. 원고에 영문명·번역 제목이 있으면 H2 아래 4mm에 muted 보조 제목으로 분리하고 그 하단부터 본문 간격을 잰다. 없는 부제·번역을 추가하지 않는다. 실제 소개 문장만 리드문으로 쓰고 후속 설명은 본문으로 되돌린다.

표지 제목만 길이에 따라 44/49, 40/45pt 순서로 조절할 수 있다. 그래도 4줄을 넘으면 의미를 보존한 부제 분리 등 편집 조건을 확인한다. 나머지 제목·본문의 크기는 문서 전체에서 유지한다.

## 세 가지 페이지 골격

**표지:** 발행자/제공 로고 x=14,y=16mm(로고 최대 32×8mm, 텍스트 12pt/600), 유형 라벨 y=36mm, 제목 x=14,y=54,w=182,h≤78mm(2–4줄), 부제 y=142,h≤22mm(최대 2줄), 추상 이미지 x=14,y=178,w=182,h=84mm, 날짜·버전 y=278mm. 제목이 짧아도 이미지·부제를 끌어올리지 않는다. 없는 발행 정보는 빈 자리로 남기며 머리말·쪽수는 생략한다.

**장 도입:** accent-soft 전면 배경, 장 번호와 H1 x=14,y=28mm, 제목 구역은 y=92mm 안에 마친다. 리드문 y=112mm, 최대 3문단. 실제 단계 정보가 있을 때만 y=220–270mm 안에 짧은 로드맵을 둔다. 본문이 짧은 절은 독립 장 도입 대신 일반 페이지 H2로 시작해도 된다.

**본문:** paper 배경, 머리말·H2·본문·자료·출처·꼬리말. 관련 설명과 근거를 가깝게 두고 1열로 읽는다. 절차·기준·방법이 주 내용인 전용 페이지에는 accent-soft 전면 배경을 쓸 수 있으나 일반 H2·12/18pt 본문 위계를 유지하고 큰 색면을 다시 겹치지 않는다.

## 간격과 구성군

- 같은 그룹 문단 뒤 초기값 10pt, H3 위 24pt·아래 10pt, 큰 블록 사이 8mm. 같은 경계의 간격은 더 큰 하나만 적용한다. 페이지 첫 소제목 위 간격과 상자 마지막 문단 뒤 간격은 제거한다.
- 설명·인용·KPI 패딩 7mm, 작은 팁 5mm, 표 셀 좌우 4mm. 기본 가로선 0.5pt, 주요 선 0.75pt. 텍스트 그룹의 실제 글자 경계와 위아래 divider 사이를 각각 5mm로 맞추며 내부 시각 간격은 2–3mm를 시작점으로 더 좁게 둔다. 수치상 패딩이 같다는 이유만으로 통과시키지 않는다.
- KPI 2–3개는 폭 182mm의 연속 tint 면을 같은 폭으로 나눈다. 3열에서 숫자가 넘치면 2열, 그래도 넘치면 전체 폭 단일 행으로 바꾼다. 칸 수를 맞추기 위해 지표를 추가하지 않는다.
- 표의 헤더와 첫 행은 함께 두고 페이지가 이어지면 제목·헤더·‘계속’을 반복한다. 긴 한 행은 항목명·열 의미를 유지하며 문단 경계에서 이어간다. 숫자는 오른쪽, 문자는 왼쪽·위쪽 정렬이다.
- 차트·표 아래 3mm에 캡션을 둔다. 각주는 마지막 콘텐츠 뒤 4mm·0.5pt 선·아래 3mm 순서로 두며 y=270mm 안에 포함한다. 출처가 길면 주석 페이지로 옮기고 연결 번호를 남긴다.

## 흐름과 분할

실제 글꼴·폭·줄바꿈과 패딩·캡션을 합한 높이로 배분한다. `textGrowth: fixed-width`와 내용 기반 높이를 사용해 읽은 실제 bounds로 다음 블록을 놓는다. 한글 제목은 의미 단위로 줄바꿈하고 숫자+단위·짧은 괄호·전문용어를 가능한 한 유지한다. 조사 한 글자·닫는 괄호만 남거나 문단 한 줄만 다음 페이지에 넘어가는 경우를 고친다.

장 전체나 긴 상자 전체를 분할 금지로 묶지 않는다. 문단·항목·표 행 경계에서 나누고 같은 절 이름·라벨과 ‘계속’을 둔다. 일반 페이지의 실제 콘텐츠 하단이 y=170mm보다 위면 다음 페이지의 관련 내용이 들어갈지 검토한다. 이는 채움 목표가 아니며 목차·장 도입·마지막 페이지·독립 도표의 이유 있는 여백은 유지한다. 내용을 늘리거나 글자를 키워 빈 공간을 채우지 않는다.

표지 다음 물리 페이지부터 표시 쪽수 1을 쓴다. 세 장의 조합 예시에서는 표지의 쪽수를 생략하고 장 도입은 1, 본문은 2다. PDF 물리 페이지·표시 쪽수·목차 목적지는 서로 따로 확인한다.
