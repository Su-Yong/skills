# Personal Skills

Codex에서 개인적으로 사용하기 위해 관리하는 스킬 저장소입니다.

## 포함된 스킬

- `feature-planner`: 아이디어나 기능 요구 사항을 구체화하고, 구현에 활용할 수 있는 계획 문서를 작성합니다.
- `feature-implementer`: 작성된 계획 문서를 바탕으로 기존 저장소를 최소한으로 변경하고 결과를 검증합니다.
- `respect-project-code`: 기존 저장소의 구조와 정책을 최대한 유지하며, 최소한의 변경으로 문제를 해결합니다.

### 구버전 스킬
- `feature-planner-old`: `feature-planner`와 `feature-implementer`의 원형이 된 구버전 스킬입니다.
